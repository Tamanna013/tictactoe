# 🕹️ Tic Tac Toe

A fun and simple Tic Tac Toe game built using **HTML**, **CSS**, and **JavaScript**.

## Features
- Two-player game: X and O alternate turns.
- Displays the winner or a draw message.
- Reset the game with a "Clear Board" button.
- Hidden board until the "Start Game" button is clicked.

## How to Play
1. Click **Start Game** to reveal the board.
2. Players take turns placing their marks (X or O).
3. Align three marks horizontally, vertically, or diagonally to win.
4. If no winner, the game declares a draw.
